## 2. 核心流程时序图模板

```mermaid
sequenceDiagram
    actor U as 用户/外部系统
    participant A as 模块A
    participant B as 模块B
    participant C as 存储/设备/第三方

    U->>A: 发起操作
    A->>B: 调用业务能力
    B->>C: 读写数据或调用外部能力
    alt 成功
        C-->>B: 成功结果
        B-->>A: 返回业务结果
        A-->>U: 展示成功
    else 失败
        C-->>B: 错误
        B-->>A: 错误码/错误原因
        A-->>U: 展示可修复提示
    end
```

### 2.1 说明

| 项 | 内容 |
|----|------|
| 触发条件 | [用户操作/定时任务/设备事件/API调用] |
| 前置条件 | [登录、配置、资源、硬件在线等] |
| 成功结果 | [最终状态/输出数据/副作用] |
| 异常路径 | [超时、权限、参数、设备离线、写入失败等] |
| 相关规则 | [RULE-xxx] |
| 相关接口 | [接口契约章节] |
| 验收用例 | [测试编号] |

## 3. 业务流程图模板

```mermaid
flowchart TD
    Start([开始]) --> Check{条件是否满足}
    Check -- 是 --> Do[执行业务动作]
    Check -- 否 --> Reject[拒绝并提示原因]
    Do --> Success([成功结束])
    Reject --> End([结束])
```

## 4. 状态机图模板

```mermaid
stateDiagram-v2
    [*] --> Created
    Created --> Running: start
    Running --> Completed: success
    Running --> Failed: error
    Failed --> Running: retry
    Completed --> [*]
```
