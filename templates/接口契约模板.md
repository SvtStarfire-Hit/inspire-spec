# 接口契约

> **使用说明**：为每个模块的公开方法填写一份契约。重点定义输入/输出/副作用/关键约定。
> 契约是模块间的“合同”——双方按合同行事，修改需双方同意。
> 每个接口必须包含：输入、输出、副作用、异常、权限、幂等性。设备通信还需包含超时/重试/心跳。

## 检查清单

- [ ] 每个 public 方法都有契约
- [ ] 输入参数有类型、必填性、含义
- [ ] 输出有类型和含义
- [ ] 副作用已声明（无则标注“无”）
- [ ] 权限已声明（无则标注“无”）
- [ ] 幂等性已声明（不适用则标注）
- [ ] 关键约定已列出（特别是容易误解的语义）
- [ ] 设备通信接口有心跳/超时/重试/幂等
- [ ] 代码中的方法签名与契约一致
- [ ] 调用方按契约使用，不依赖未声明的行为
